# adventurejs

Please read https://javascript.plainenglish.io/functional-javascript-writing-a-simple-command-line-game-335ab9fcc005

This repo contains a working version of the adventure maze game, now converted to TypeScript.

## To build
```shell
npm install
npm run build
```

## To run the fight example
```shell
npm run build
node dist/examples/fight.js
```

## To run the game
```shell
npm run build
node dist/maze.js
```
